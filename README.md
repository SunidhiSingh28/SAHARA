# SAHARA (सहारा) 🏛️

> **Citizen-Focused Public Service & Guidance Engine**

SAHARA is a modern, intuitive, and accessible web application designed to simplify navigation through public services, document requirements, and administrative procedures for citizens.

---

## ✨ Features

- **Dynamic Interactive Intro**: Fluid branded intro animation with multi-layered SVG/PNG graphics and bilingual English & Hindi typography (*SAHARA / सहारा*).
- **Intelligent Guidance Search**: Search bar with audio readout / text-to-speech support for accessibility.
- **Service Exploration**:
  - 📁 **Document Upload & Verification Guidance**
  - 💡 **Life Events Navigation** ("What are you trying to do?")
  - 🏛️ **Service Catalog** (Certificates, Schemes, Licenses, Social Welfare)
  - ⏳ **Application Tracker**
- **Bilingual Support**: Built-in translation and language switching (English / Hindi).
- **Responsive & Accessible Design**: Engineered with clean CSS, glassmorphism accents, and mobile-friendly touch interfaces.
